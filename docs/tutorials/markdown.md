MarkDown은 GitHub 혹은 문서 위주의 사이트(e.g, documentation, 튜토리얼)에 많이 쓰이는 사용하기 쉬운 `.md` 확장자의 포맷으입니다. 일반 텍스트 문서를 쓰듯이 작성하고 GitHub나 VSCode, IntelliJ, MarkText, Zettlr, Obsidian 등 다양한 Markdown 뷰어에서 렌더링 해 볼 수 있습니다. 또한, 렌더링 없이도 보기 편하도록 설계되어 굳이 별도 뷰어가 없어도 되긴 합니다. Discord 등의 채팅 앱도 MarkDown 문법으로 작성이 가능하며 렌더링 이 경우 렌더링을 해줍니다.

VSCode/VSCodium에서는 CTRL+SHIFT+V로 Preview 띄울 수 있습니다. 아니면 우상단에서 Open Preview to the Side 선택해주세요

## 기본적인 내용

마크다운은 엔터를 눌러도 렌더링되는 줄이 바뀌지 않습니다. 블록을 구분하기 위해서는 빈 줄이 사이에 있어야 하며, 아닐 경우 이어서 나오게 됩니다. 

Header는 `#` 뒤에 스페이스를 두고 내용을 적으면 됩니다. 헤더를 기반으로 Markdown All in One등의 플로그인은 자동으로 ToC(목차)를 생성해 주기도 합니다. 더 큰 헤더(e.g,`#`가 `##`보다 상위)는 아래 헤더들을 포함하는 형태입니다.

```markdown
# 헤더 1
## 헤더 2
### 헤더 3

# 2번째 헤더 1
## 2번째 헤더의 헤더 2
```

리스트의 경우 `-` 혹은 숫자를 사용해 표현하고, 하위 아이템은 다음 줄에서 탭으로 간격을 주어 씁니다.

```markdown
- 1번 리스트
    - 1-1
        - 1-1-1
    - 1-2
- 2번 리스트
```
```markdown
1. 1번 리스트
    1. 1번의 1번 아이템
    2. 1번의 2번 아이템
    3. 1번의 3번 아이템
2. 2번 리스트
```

링크의 경우 `[텍스트](링크 URI)` 형태로 표현됩니다. 렌더링되지 않은 MarkDown 파일을 보고 있다면 Ctrl+클릭으로 이동 가능합니다.

```markdown
[Git 튜토리얼 문서](./git.md)
```

마지막으로 백틱은 코드를 감쌀 수 있습니다. 백틱 3개 사이에는 블록을 넣을 수 있으며, 이 경우 시작 백틱 옆에 원하는 언어를 지정 가능합니다.(e.g, JS, TS, Java, Python, Markdown, HTML, CSS...)

```java
public class Main{

}
```
```html
<div></div>
```
